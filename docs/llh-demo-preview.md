# Local LLH authentication preview

The previous local buyer/library demo has been removed. Task 01 contains registration, email-code verification, PIN setup, returning sign-in and verified PIN recovery. Task 02 replaces the welcome placeholder with the main Dashboard; its progress is explicitly illustrative and all four feature cards are nonfunctional placeholders.

See [LLH Task 01](llh-auth-task01.md) for the local URL, demo testing instructions, temporary-state behavior, backup, changed files and validation commands.

The public build does not contain the demo adapter or credentials. It has no working authentication until a production backend design is reviewed and implemented in a later task. Publishing Tasks 01 and 02 together is now authorized by the owner; see [Task 02 release notes](llh-dashboard-task02.md).
