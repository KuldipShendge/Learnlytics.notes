# Typography matched to the old dashboard

The old sidebar rules in `D:/website/css/style.css` use Manrope at 14px,
500 weight and 1.5 line height, with 600 for the active item. The old dashboard
heading uses 600 weight and -0.6px letter spacing; light-theme section headings
use 600 weight with -0.4px or -0.25px spacing.

The current site now uses these settings for navigation, career tabs and
section headings. Main titles keep their responsive hierarchy, with a 48px
homepage desktop title and 42px product desktop titles. Body copy remains
regular weight; numeric prices, statistics and small labels retain emphasis.
Only typography changed; blue colours, content and component structure stay intact.

`assets/fonts/Manrope-Medium.ttf` supplies the actual 500 face, alongside the
existing 400, 600, 700 and 800 faces. It is Manrope 4.504, matching the existing
files, and is served locally without a Google Fonts request.

Source: [Manrope font project](https://github.com/googlefonts/manrope/blob/6f81ebecdf65e4463b798cc07b16a4f8d5216917/fonts/ttf/manrope-medium.ttf).
